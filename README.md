# Customer Churn Prediction with PySpark

## Project Overview

This project builds a machine learning model to predict customer churn using **PySpark** and **Random Forest**.

The goal is to identify customers at risk of leaving and provide insights that help businesses improve retention strategies.

---

## Technologies Used

- Python
- PySpark
- Machine Learning
- Random Forest
- Cross Validation
- Seaborn
- Matplotlib

---

## Machine Learning Pipeline

1. Data cleaning and preprocessing
2. Feature engineering
3. VectorAssembler
4. Random Forest model
5. Hyperparameter tuning with CrossValidator
6. Model evaluation (AUC / ROC)

---

## Key Insights

The analysis reveals several patterns related to churn:

- Customers with **shorter tenure** are more likely to leave.
- Certain **contract types** show higher churn rates.
- **Total spending** patterns help identify customer segments at risk.

---

## Business Impact

Predicting churn allows companies to:

- Identify high-risk customers
- Implement retention strategies
- Improve customer satisfaction
- Reduce revenue loss
